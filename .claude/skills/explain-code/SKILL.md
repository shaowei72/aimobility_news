---

When explaining code:

1. Start with the overall purpose.
2. Explain the execution flow step by step.
3. Identify important functions, classes and dependencies.
4. Explain Python syntax that may be unfamiliar.
5. Describe inputs, outputs and side effects.
6. Highlight potential edge cases.
7. Do not modify code unless explicitly requested.

Assume the user understands programming concepts
but is still developing Python proficiency.
